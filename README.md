# ToxicBots — токсичные боты для Counter-Strike: Source

Боты в CS:S отвечают на то, что ты **пишешь в чат или говоришь в микрофон**, с матом и подколами,
ноют «бляя, проебали раунд», после каждого раунда выясняют, **кто уёбищнее всех играл**
(по реальным килам, смертям и урону), а в конце катки выкладывают «Топ уёбищ».

Мод сделан на встроенном в CS:S **VScript** (появился в обновлении от февраля 2025).
**SourceMod, MetaMod и `-insecure` не нужны** — просто кидаешь папку в игру.

## Установка (1 минута)

1. Скачай репозиторий (**Code → Download ZIP**) и распакуй.
2. Скопируй папку **`toxicbots`** в
   `...\steamapps\common\Counter-Strike Source\cstrike\custom\`
   Проверка: должен существовать файл
   `cstrike\custom\toxicbots\scripts\vscripts\mapspawn.nut`
3. В Steam пропиши параметры запуска `-novid +exec toxicbots` (подробно — ниже).
4. Создай сервер с ботами (**Новая игра**, боты добавятся сами или `bot_add` в консоли).
   В консоли (`~`) появится: `[ToxicBots] загружен: 36 интентов, 120 готовых ответов`.
5. Пиши в чат что угодно — боты ответят.

### Параметры запуска в Steam
Steam → ПКМ по Counter-Strike: Source → **Свойства → Общие → Параметры запуска**:
```
-novid +exec toxicbots
```
* `+exec toxicbots` — включает `cl_showtextmsg 1` (без него текст ботов не видно). **Это единственное, что нужно.**
* `-novid` — просто пропустить заставку (по желанию).
* `-insecure`, SourceMod, MetaMod — **не нужны**, VScript работает в обычной игре с ботами.

## Голоса ботов 🔊
Есть два вида озвучки, работают вместе:

**1. Готовые фразы прямо в игре.** Ничего ставить не надо: 10 записанных реплик (`toxicbots/sound/toxicbots/*.wav`)
звучат из игры, когда бот их говорит. Два голоса — проигравшие и победители:

| файл | фраза | когда |
|---|---|---|
| lose1–lose4 | «Бляя, проебали раунд», «Ну пиздец, опять слили», «Сука, как мы это проебали?», «Проебали. Кто-нибудь вообще стрелял?» | команда ботов слила раунд |
| matchlose1 | «Бляя, проебали катку» | проиграли матч |
| win1–win3 | «Изи раунд. Идите плачьте», «Минус раунд, раки», «Изи. Даже напрягаться не пришлось» | боты выиграли раунд |
| matchwin1 | «Изи катка. Удаляйте игру, раки» | выиграли матч |
| kill1 | «Следующего, пожалуйста. Этот сломался» | бот убил тебя |

**2. Живая озвучка ВСЕХ ответов** (их миллионы, заранее не запишешь) — программа рядом с игрой,
оффлайн-синтез речи Piper. **Каждому боту свой голос** из 8 пресетов:
`Гопник-бас`, `Дерзкий школьник`, `Спокойный токсик`, `Стерва`, `Пьяный дед`, `Писклявый`, `Тильтер-тараторка`, `Злой робот`.

Эта же программа слушает твой микрофон, так что боты и слышат тебя, и отвечают голосом:
1. Нужен Python 3.10–3.13, лучше 3.12 (`winget install Python.Python.3.12` или python.org, галочка «Add to PATH»).
2. Один раз запусти `voice\УСТАНОВИТЬ_ЗАВИСИМОСТИ.bat` (ставит `vosk sounddevice pynput numpy piper-tts`
   в `%LOCALAPPDATA%\ToxicBots\venv`, не в папку игры). Или вручную: `py -m pip install vosk sounddevice pynput numpy piper-tts`.
3. Запусти `cstrike\custom\toxicbots\voice\ЗАПУСТИТЬ_ГОЛОС.bat` и не закрывай окно
   (в первый раз скачает распознавание речи ~45 МБ и голоса ~60 МБ каждый в `%LOCALAPPDATA%\ToxicBots`).
4. В игре **зажимаешь K** (обычный войс) и говоришь — бот отвечает в чат **и голосом**.

Опции (дописать после `ЗАПУСТИТЬ_ГОЛОС.bat` в командной строке):
`--demo` — прослушать все 8 голосов · `--no-mic` — только озвучка ботов · `--no-tts` — только микрофон ·
`--mode always` — слушать без кнопки · `--voices dmitri,ruslan` — только мужские голоса · `--big` — точнее распознаёт (1.8 ГБ).

Выключить голоса в игре: `config.nut` → `clips_enabled = false`, `tts_enabled = false`.

## Что умеет

| | |
|---|---|
| **Ответы на чат/голос** | 36 тем: оскорбления (с зеркалом твоего же слова: «Еблан — это твой пик»), «что за хуйня», «ты чё такой дерзкий», «тебя чё ебёт», «иди нахуй», «ты чё глухой», мамки, читы, gg/изи, лаги, угрозы «1 на 1», «ты бот?», смех, приветы, рифмы («да» → «пизда», «триста» → …) и др. |
| **Классика** | все 120 твоих пар (121–240) — если фраза **похожа** (опечатки, другой порядок, без запятых), бот может ответить именно так |
| **Генератор** | шаблоны + слоты + мат-приставки: **38 260** уникальных ответов, с приставками/добивками — **~26 млн** вариантов |
| **Распознавание** | опечатки (`ебланн`, `далбаёб`), растянутые буквы (`еблааан`), латиница-«похожие» буквы (`e6лан`), **английская раскладка** (`nst t,kfy` → «ты еблан»), транслит (`ty eblan`), цензура звёздочкой (`х*й`) |
| **Тиммейты** | «бляя, проебали раунд», «проебали катку», комментарии в командный чат, отвечают на «го б», «вы раки», «проебали» |
| **Кто уёбищнее всех** | после раунда разбор худшего в проигравшей команде (килы/смерти/урон), худший бот огрызается; в конце матча — «Топ уёбищ катки» |
| **События** | бот убил тебя (отдельно — в голову), ты убил бота, ты убил своего, ты умер первым, начало карты |
| **Контекст** | в ответах реальный ник, счёт (`ты 3-11`), карта, оружие, сколько раз бот тебя убил; если ты играешь хорошо — обвиняют в читах |

Команды в чате: `!tb on`, `!tb off`, `!tb stat` (таблица худших), `!tb debug`.

## Настройка
* Шансы, скорость «печати», включение голоса — `toxicbots/scripts/vscripts/toxicbots/config.nut`.
* Фразы — `phrases/*.txt` (формат описан в начале каждого файла). После правки:
  ```
  python tools/build.py      # пересобрать data.nut и посчитать варианты
  python tools/sim.py        # проверить ответы без игры
  python tools/sim.py --events
  ```

## Как устроено
```
toxicbots/                        <- эта папка кладётся в cstrike/custom/
  scripts/vscripts/mapspawn.nut   автозапуск на каждой карте
  scripts/vscripts/toxicbots/
    main.nut     события игры, статистика, чат ботов, приём голоса
    core.nut     нормализация, нечёткий поиск (Левенштейн), генератор
    data.nut     фразы (собирается из phrases/)
    config.nut   настройки
  cfg/toxicbots.cfg
  sound/toxicbots/*.wav           готовые озвученные фразы
  voice/         микрофон (Vosk) -> scriptdata/toxicbots_voice.txt
                 озвучка (Piper) <- scriptdata/toxicbots_tts.txt
phrases/         исходники фраз
tools/           сборка, симулятор, эталон движка на Python, тесты на Squirrel
```

## Если не работает
* В консоли нет `[ToxicBots] загружен` → проверь путь (п.2) и что игра обновлена (VScript есть только в версии после февраля 2025).
* Боты «молчат» → `cl_showtextmsg 1` в консоли; `!tb debug` покажет, какая тема распозналась.
* Голос: в окне программы видно, что распознано (`>> ...`); в игре появляется серое `[голос] ...`.
  Не тот микрофон → `ЗАПУСТИТЬ_ГОЛОС.bat --list`, потом `--device N`.
