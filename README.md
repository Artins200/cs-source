# ToxicBots — токсичные боты для Counter-Strike: Source

Боты в CS:S отвечают на то, что ты **пишешь в чат или говоришь в микрофон**, с матом и подколами,
ноют «бляя, проебали раунд», после каждого раунда выясняют, **кто уёбищнее всех играл**
(по реальным килам, смертям и урону), а в конце катки выкладывают «Топ уёбищ».

Но они **не всегда токсичные**: у каждого бота свой характер, и они помнят, как ты себя ведёшь.
Общаешься нормально — отвечают нормально и **реально выполняют приказы** («за мной на Б», «прикройте»,
«дефузьте»). Хамишь — посылают.

Мод сделан на встроенном в CS:S **VScript** (появился в обновлении от февраля 2025).
**SourceMod, MetaMod и `-insecure` не нужны** — просто кидаешь папку в игру.

## Установка (1 минута)

1. Скачай репозиторий (**Code → Download ZIP**) и распакуй.
2. Скопируй папку **`toxicbots`** в
   `...\steamapps\common\Counter-Strike Source\cstrike\custom\`
   Проверка: должен существовать файл
   `cstrike\custom\toxicbots\scripts\vscripts\mapspawn.nut`
3. В Steam пропиши параметры запуска `-novid +exec toxicbots` (подробно — ниже).
4. Создай сервер с ботами (**Новая игра**, боты добавятся сами или `bot_add` в консоли).
   В консоли (`~`) появится: `[ToxicBots] загружен: 58 интентов, 120 готовых ответов`.
5. Пиши в чат что угодно — боты ответят.

### Параметры запуска в Steam
Steam → ПКМ по Counter-Strike: Source → **Свойства → Общие → Параметры запуска**:
```
-novid +exec toxicbots
```
* `+exec toxicbots` — включает `cl_showtextmsg 1` (без него текст ботов не видно). **Это единственное, что нужно.**
* `-novid` — просто пропустить заставку (по желанию).
* `-insecure`, SourceMod, MetaMod — **не нужны**, VScript работает в обычной игре с ботами.

**Слабый ПК / ноутбук на встроенной видеокарте:**
```
-novid +exec toxicbots +exec toxicbots_fps
```
`toxicbots_fps.cfg` — облегчённая графика (без теней, HDR, блума, травы, физики трупов, FPS ограничен 120,
чтобы ноутбук не перегревался). Это обычные настройки игры; часть из них сохранится, вернуть можно в меню «Видео».
Голос в этом случае запускай через `voice\ЗАПУСТИТЬ_ГОЛОС_СЛАБЫЙ_ПК.bat`.

## Голоса ботов 🔊
Есть два вида озвучки, работают вместе:

**1. Готовые фразы прямо в игре.** Ничего ставить не надо: 10 записанных реплик (`toxicbots/sound/toxicbots/*.wav`)
звучат из игры, когда бот их говорит. Два голоса — проигравшие и победители:

| файл | фраза | когда |
|---|---|---|
| lose1–lose4 | «Бляя, проебали раунд», «Ну пиздец, опять слили», «Сука, как мы это проебали?», «Проебали. Кто-нибудь вообще стрелял?» | команда ботов слила раунд |
| matchlose1 | «Бляя, проебали катку» | проиграли матч |
| win1–win3 | «Изи раунд. Идите плачьте», «Минус раунд, раки», «Изи. Даже напрягаться не пришлось» | боты выиграли раунд |
| matchwin1 | «Изи катка. Удаляйте игру, раки» | выиграли матч |
| kill1 | «Следующего, пожалуйста. Этот сломался» | бот убил тебя |

**2. Живая озвучка ВСЕХ ответов** (их миллионы, заранее не запишешь) — программа рядом с игрой,
оффлайн-синтез речи Piper. **Каждому боту свой голос** из 8 пресетов:
`Гопник-бас`, `Дерзкий школьник`, `Спокойный токсик`, `Стерва`, `Пьяный дед`, `Писклявый`, `Тильтер-тараторка`, `Злой робот`.

Эта же программа слушает твой микрофон, так что боты и слышат тебя, и отвечают голосом:
1. Нужен Python 3.10–3.13, лучше 3.12 (`winget install Python.Python.3.12` или python.org, галочка «Add to PATH»).
2. Один раз запусти `voice\УСТАНОВИТЬ_ЗАВИСИМОСТИ.bat` (ставит `vosk sounddevice pynput numpy piper-tts`
   в `%LOCALAPPDATA%\ToxicBots\venv`, не в папку игры). Или вручную: `py -m pip install vosk sounddevice pynput numpy piper-tts`.
3. Запусти `cstrike\custom\toxicbots\voice\ЗАПУСТИТЬ_ГОЛОС.bat` и не закрывай окно
   (в первый раз скачает распознавание речи ~45 МБ и голоса ~60 МБ каждый в `%LOCALAPPDATA%\ToxicBots`).
4. В игре **зажимаешь K** (обычный войс) и говоришь — бот отвечает в чат **и голосом**.

Опции (дописать после `ЗАПУСТИТЬ_ГОЛОС.bat` в командной строке):
`--lite` — для слабого ПК (то же, что `ЗАПУСТИТЬ_ГОЛОС_СЛАБЫЙ_ПК.bat`) · `--demo` — прослушать все 8 голосов · `--no-mic` — только озвучка ботов · `--no-tts` — только микрофон ·
`--mode always` — слушать без кнопки · `--voices dmitri,ruslan` — только мужские голоса · `--big` — точнее распознаёт (1.8 ГБ).

Выключить голоса в игре: `config.nut` → `clips_enabled = false`, `tts_enabled = false`.

## Что умеет

| | |
|---|---|
| **Ответы на чат/голос** | 58 тем (у каждой — токсичные и нормальные ответы): оскорбления (с зеркалом твоего же слова: «Еблан — это твой пик»), «что за хуйня», «ты чё такой дерзкий», «тебя чё ебёт», «иди нахуй», «ты чё глухой», мамки, читы, gg/изи, лаги, угрозы «1 на 1», «ты бот?», смех, приветы, рифмы («да» → «пизда», «триста» → …), «чё ты такой слабый», «противник хорошо играет», «переобулся», «дай денег» и др. |
| **Классика** | все 120 твоих пар (121–240) — если фраза **похожа** (опечатки, другой порядок, без запятых), бот может ответить именно так |
| **Генератор** | шаблоны + слоты + мат-приставки: **50 000+** уникальных ответов (+ нормальные ответы на все темы), с приставками/добивками — **~34 млн** вариантов |
| **Распознавание** | опечатки (`ебланн`, `далбаёб`), растянутые буквы (`еблааан`), латиница-«похожие» буквы (`e6лан`), **английская раскладка** (`nst t,kfy` → «ты еблан»), транслит (`ty eblan`), цензура звёздочкой (`х*й`) |
| **Тиммейты** | «бляя, проебали раунд», «проебали катку», комментарии в командный чат, **выполняют приказы**, реагируют на «давайте быть командой», замечают твой хороший раунд |
| **Кто уёбищнее всех** | после раунда разбор худшего в проигравшей команде (килы/смерти/урон), худший бот огрызается; в конце матча — «Топ уёбищ катки» |
| **События** | бот убил тебя (отдельно — в голову), ты убил бота, ты убил своего, ты умер первым, начало карты |
| **Контекст** | в ответах реальный ник, счёт (`ты 3-11`), карта, оружие, сколько раз бот тебя убил; если ты играешь хорошо — обвиняют в читах |

Команды в чате: `!tb on`, `!tb off`, `!tb stat` (таблица худших), `!tb mood` (уважение ботов к тебе),
`!tb toxic 0.3` (характер: 0 — все добрые, 1 — все токсики), `!tb duel` (отменить дуэль), `!tb debug`.

## Характер ботов и приказы

**Настроение.** Каждому боту при появлении выпадает характер (от «душки» до токсика, среднее задаёт
`toxicity` в `config.nut` или `!tb toxic 0.3` в чате). Плюс общее **уважение к тебе** (0–100, `!tb mood`):

| растёт | падает |
|---|---|
| «пожалуйста», «ребят», «пацаны», «спасибо», похвала, «извини» | оскорбления, мамки, «вы раки» |
| «давайте быть командой» / «хватит токсичить» (ещё и 2,5 мин перемирия) | убил своего |
| хороший раунд (2+ кила или 250+ урона) | подколы про счёт, «изи», «читер» |

Чем выше уважение и мягче характер, тем чаще бот отвечает нормально («Принял, иду за тобой на Б»,
«Ничего, отыграемся», «Нормально попал»). Мат в твоём сообщении сам по себе не обида — обида, когда обзывают.

**Приказы тиммейтам — работают по-настоящему.** Мод отдаёт от твоего имени радио-команду игры
(как будто ты нажал Z/X/C), и боты реагируют своим ИИ:

| пишешь / говоришь | радио | что делают боты |
|---|---|---|
| «за мной», «го за мной на Б», «пошли со мной» | Follow me | идут за тобой |
| «прикройте», «подстрахуй» | Cover me | идут за тобой |
| «все на Б», «стак на А», «давайте командой» | Stick together | держатся с тобой |
| «помогите», «сюда», «ко мне», «они тут» | Need backup | бегут к тебе |
| «дефузьте», «раздефузьте» (ты CT, бомба стоит) | Need backup | бегут к тебе; стоишь у бомбы — увидят её и пойдут дефузить |
| «дефайте бомбу», «охраняйте плент», «не пускайте спецов» (ты T, бомба стоит) | Hold position | садятся сторожить бомбу там, где ты стоишь: «Сижу на бомбе. Пусть только попробуют» |
| то же, но бомбу ещё не поставили | Cover me | идут прикрывать тебя: «Бомба не заложена, гений. Но окей, прикрою» |
| «держим плент», «охраняйте» (ты CT) | Hold position | держат точку |
| «держите позицию», «стойте тут», «ждите» | Hold position | занимают позицию |
| «вперёд», «раш», «пушим» | Go go go | идут в атаку |
| «назад», «отходим» | Fall back | отступают |
| «щас рванёт», «валите» | Get out of there | бегут от бомбы |
| «чисто», «бомбы нет» (ты CT на пленте, бомба стоит) | Sector clear | вычёркивают плент, где ты стоишь, и ищут на другом |

Нормально попросил — почти всегда «Принял». Нахамил в той же фразе («за мной, еблан») — «После
„еблан“ сам свои приказы выполняй». Весь матч поливал всех — шанс отказа большой.
Боты, как и с обычным радио, могут не послушаться, если заняты (стреляют, закупаются, ставят/дефузят бомбу).

**Подъёб про счёт** («у тебя 0 килов», «Kirk посмотри на свой счёт»): бот смотрит на свой **реальный** счёт
и твой — если он лучше, тычет тебя носом («У меня 7-4, у тебя 3-11»), если хуже — оправдывается или признаёт.

**«Я поддаюсь» / «ща без поддавок».** Боты запоминают, с каким счётом ты это написал. Сливаешь дальше —
«Без поддавок, говоришь? Опять ноль за раунд». Раздал после этого — «Бля, он реально поддавался. До этого
2-9, а тут 3 за раунд», а враги: «Ладно, мы тоже без поддавок теперь». Хороший раунд и без этого
не останется незамеченным: «О, нормально раздал. Можешь же, когда хочешь».

## Дуэли, дроп, кики, читы и срачи между ботами

**Дуэли «на ножах» и на любом оружии.** «давай на ножах», «го раунд на диглах», «пвп на AWP», «на пистолетах»,
«на снайперках», «на калашах», «на эмках», «на дробовиках», «на гранатах»… Бот соглашается (или нет — если ты
весь матч хамил или уже кидал на дуэли). Если раунд только начался (до 35 с), дуэль идёт сразу, иначе — со
следующего раунда. На раунд дуэли:
* у ботов отбирается всё, кроме ножа, бомбы и нужного оружия, а нужное им выдаётся (кладётся под ноги);
* их ИИ ограничивается квотами игры `bot_allow_*` (как `bot_knives_only`), чтобы они не закупались стволами;
* деньги ботов не тратятся; в следующем раунде всё возвращается как было («Всё, поигрались, теперь всерьёз»).

По умолчанию дуэль действует на **всех** ботов (`duel_scope = "all"`), только на противников — `"enemy"`.
Тебя самого не разоружают — но если в ножевом раунде убьёшь бота **из AWP**, начнётся: «Ты чё, сука, мы ж на ножах
договорились, а ты с AWP!», остальные подхватят, уважение упадёт, и это будут **припоминать**
(«Это тот, который с AWP в раунде на ножах бегал?») и отказываться от новых дуэлей.
Боты и сами иногда предлагают: «Скучно. Давай на ножах, Игрок» — ответь «да»/«го»/«+» или «нет».

**«Дропни калаш».** «дропни», «скинь ствол», «дай авп», «кинь мп5»… Тиммейт кладёт оружие тебе под ноги
(если у тебя занят этот слот — нажми G и подбери). Далеко — «Подходи, я не курьер», и скинет, когда подойдёшь.
Нет такого — «Калаш? Нету. У меня глок, и то не дам». Нахамил — «С таким базаром — только нож в спину».
Попросил у врага — «Подходи ближе, я тебе бесплатно в голову дропну».

**Кики.** Если бот 3 раунда подряд худший в команде — свои предлагают его кикнуть, голосуют, он возмущается;
напишешь «да» / «кикай» — мод **реально кикает бота** (`kickid`, на его место `bot_quota` добавит нового).
Сам можешь: «кикните Kirk», «го кик Васю». Если худший или токсик — ты, предложат кикнуть тебя («…жаль, он хост»).

**Обвинения в читах.** 3 хедшота подряд — «У тебя прицел липкий, сколько стоит?», 3 кила за раунд — «Он сквозь стены
смотрит», эйс — «ЭЙС?! Ну всё, 100% читы», один и тот же бот убит дважды подряд — «Опять я? Чё ты ко мне привязался».
Тиммейты то защищают, то подливают. Ноль урона за раунд — «Ты чё, с закрытыми глазами стреляешь?».

**Живость.**
* Боты **срутся между собой**: один ответил тебе — другой подъёбывает его («Vasya, ты бы помолчал, у тебя 1-6»), тот огрызается.
  Бот убил бота — подкол или нытьё. Худший бот огрызается конкретно тому, кто его обосрал.
* **Бот-тролль** (один случайный): угорает, когда ты обсираешь других («АХАХАХ, Vasya, ну ты получил»),
  не обижается на оскорбления («Обидел-обидел. Пойду поплачу. Ахахах, шучу»), шутит над ботами в конце раунда.
* **«Ты сам нас позвал»**: позвал за собой, а через полминуты назвал всех нубами — «Ты сам сказал идти за тобой.
  Мы пошли. Теперь мы нубы? Охуеть логика». Не послушались, а ты орёшь — «Я ж говорил, не пойду. И правильно сделал».
* **Сменил команду** — бывшие тиммейты: «Ахахах, переобулся! Крыса съебала к ним», новые: «О, к нам перебежчик».
* Пишут как люди: иногда с маленькой буквы, без точки, в два сообщения подряд, с опечаткой и «*исправлением» следом.

## Производительность
* Нечёткий поиск ускорен примерно в 4–5 раз (быстрый отсев слов до расчёта Левенштейна) — ответ на сообщение
  считается за ~1–7 мс, без подвисаний кадра.
* Скрипт «спит», когда делать нечего: просыпается к ближайшему сообщению бота, файл голоса без запущенной
  программы проверяется раз в 3 с, а одинаковое содержимое не разбирается повторно.
* Программа голоса работает с пониженным приоритетом и ограничивает потоки процессора для озвучки
  (`--threads N`); `--lite` — 2 голоса вместо 4 (вдвое меньше ОЗУ), 1 поток, короткие фразы.
  Голоса загружаются при запуске, а не посреди раунда.
* Если лагает сама игра — `+exec toxicbots_fps` (см. выше) и меньше ботов (`bot_quota 6`).

## Настройка
* Шансы, скорость «печати», включение голоса — `toxicbots/scripts/vscripts/toxicbots/config.nut`.
* Фразы — `phrases/*.txt` (формат описан в начале каждого файла). После правки:
  ```
  python tools/build.py      # пересобрать data.nut и посчитать варианты
  python tools/sim.py        # проверить ответы без игры
  python tools/sim.py --events
  ```

```
  scripts/vscripts/mapspawn.nut   автозапуск на каждой карте
  scripts/vscripts/toxicbots/
    main.nut     события игры, статистика, чат ботов, приказы, приём голоса
    fun_items.nut   дроп оружия, дуэли (отбор/выдача оружия, bot_allow_*)
    fun_social.nut  срачи ботов, тролль, читы, кики, смена команды, опечатки
    core.nut     нормализация, нечёткий поиск (Левенштейн), генератор
    data.nut     фразы (собирается из phrases/)
    config.nut   настройки
  cfg/toxicbots.cfg, toxicbots_fps.cfg (облегчённая графика)
  sound/toxicbots/*.wav           готовые озвученные фразы

                 озвучка (Piper) <- scriptdata/toxicbots_tts.txt
phrases/         исходники фраз

```

## Если не работает
* В консоли нет `[ToxicBots] загружен` → проверь путь (п.2) и что игра обновлена (VScript есть только в версии после февраля 2025).
* Боты «молчат» → `cl_showtextmsg 1` в консоли; `!tb debug` покажет, какая тема распозналась.
* Кик / ограничение оружия в дуэли не срабатывает («Кик не прошёл») → серверные команды из скрипта выключены.
  Пропиши в консоли `sv_allow_point_servercommand always` (или добавь в `cfg/toxicbots.cfg`). Отбор оружия в дуэли
  работает и без этого.
* Дуэль «залипла» (боты только с ножами) → `!tb duel` или в консоли `bot_all_weapons`.
* Голос: в окне программы видно, что распознано (`>> ...`); в игре появляется серое `[голос] ...`.
  Не тот микрофон → `ЗАПУСТИТЬ_ГОЛОС.bat --list`, потом `--device N`.
